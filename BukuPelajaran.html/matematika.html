Matematika

Matriks, Limit, dan Statistika

Buku siswa Matematika kelas XI yang membahas matriks, limit fungsi, dan statistika, tiga topik penting sebagai bekal berpikir logis dan membaca data.

📘 Kelas XI🧩 3 Bab⭐ Matematika

1. Gambaran Isi Buku

Buku ini mengajak kamu memakai matematika sebagai alat: matriks untuk mengelola data berbentuk tabel, limit untuk memahami perilaku fungsi di sekitar suatu titik, dan statistika untuk meringkas serta menafsirkan data. Ketiganya sering muncul di dunia kerja, misalnya pengolahan data, pemrograman, hingga analisis hasil produksi.

2. Peta Materi

• Bab 1, Matriks: Mengenal bentuk dan jenis matriks, operasi penjumlahan, pengurangan, perkalian, serta determinan dan invers matriks 2 × 2.
• Bab 2, Limit Fungsi: Memahami arti mendekati suatu nilai, menghitung limit dengan substitusi langsung, dan menyelesaikan bentuk 0/0 dengan pemfaktoran.
• Bab 3, Statistika: Menyajikan data, menghitung mean, median, modus, serta ukuran penyebaran seperti jangkauan, lalu menafsirkannya.

3. Konsep Kunci

Determinan dan invers matriks 2 × 2. Untuk A = [a b ; c d] (baris dipisah titik koma), determinan det(A) = ad − bc. Jika det(A) ≠ 0, maka A−1 = 1/det(A) × [d −b ; −c a].
Limit. Coba substitusi langsung. Jika hasilnya 0/0, faktorkan lalu sederhanakan.
Data. Mean = jumlah data ÷ banyak data; median = nilai tengah data terurut; modus = nilai yang paling sering muncul; jangkauan = data terbesar − data terkecil.

Hafalkan polanya, tetapi pahami alasannya: invers hanya ada bila determinan tidak nol, karena kita membagi dengan nilai determinan.

4. Tips Belajar

Kerjakan contoh soal dengan tangan, jangan hanya membaca. Untuk matriks, cek hasil invers dengan mengalikannya kembali ke matriks awal (hasilnya harus matriks identitas). Untuk statistika, selalu urutkan data dulu sebelum mencari median.

📝 Latihan Singkat dan Pembahasan

Soal 1. Tentukan determinan dan invers dari A = [3 1 ; 5 2].
Pembahasan: det(A) = 3·2 − 1·5 = 1, sehingga A−1 = 1/1 × [2 −1 ; −5 3] = [2 −1 ; −5 3]. Cek: A × A−1 = [1 0 ; 0 1].

Soal 2. Hitung lim x→3 (x² − 9)/(x − 3).
Pembahasan: Substitusi langsung menghasilkan 0/0. Faktorkan: (x − 3)(x + 3)/(x − 3) = x + 3, jadi limitnya 3 + 3 = 6.

Soal 3. Data: 6, 7, 7, 8, 9, 10, 10, 10, 12. Tentukan mean, median, modus, dan jangkauan.
Pembahasan: Jumlah = 79, banyak data = 9, mean = 79/9 ≈ 8,78. Median = data ke-5 = 9. Modus = 10. Jangkauan = 12 − 6 = 6.
